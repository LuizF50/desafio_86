A Jornada do Herói: Batalha de Palavras ⚔️📝


No mundo mágico da programação, você é um poderoso mago que deve ajudar a proteger o reino das palavras encantadas que estão fora de ordem! Sua missão é criar um feitiço em JavaScript que reordene uma lista de palavras mágicas, facilitando novas conjurações e encantamentos.

👨‍💻O Desafio:

Você receberá uma string com várias palavras, separadas por espaços.
Seu objetivo é retornar uma nova string com as palavras ordenadas em ordem alfabética.
As palavras devem ser separadas por um único espaço na nova string.

🛠️Entradas e Saídas:

Exemplo de entrada: "unicórnio mago dragão elfo feiticeiro"

Saída esperada: "dragão elfo feiticeiro mago unicórnio" ➡️ "dragão elfo feiticeiro mago unicórnio"
